# UCBFound

Sistema web de objetos perdidos y encontrados para la comunidad de la UCB.
Proyecto de Ingeniería de Software creado a partir del proyecto base `parcel-jest-base`.

## Instalar dependencias

```bash
npm install
```

## Comandos

| Comando | Para qué sirve |
|---|---|
| `npm start` | Levanta la app en http://localhost:1234 |
| `npm test` | Corre las pruebas unitarias (Jest) y guarda el registro TDD |
| `npm run build` | Genera la versión de producción |
| `npm run lint` | Revisa el estilo del código con ESLint |
| `npm run cypress` | Abre las pruebas E2E con Cypress |
| `npm run semantic-commits-on` | Activa la validación de commits semánticos |
